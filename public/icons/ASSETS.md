# Icon Assets

Place your icon SVG files here:

- `icon-192.svg` - PWA icon 192x192
- `icon-512.svg` - PWA icon 512x512
- `magic-token.svg` - Magic token icon
- `magic-wand.svg` - Magic wand icon (for send button)

The app currently uses emoji placeholders, but will use these SVG files when available.
