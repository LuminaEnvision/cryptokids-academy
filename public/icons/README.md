# PWA Icons

Required for installable KiddoPay:

| File | Size | Purpose |
|------|------|---------|
| `icon-192.png` | 192×192 | Standard icon |
| `icon-512.png` | 512×512 | Splash / high-res |
| `icon-512-maskable.png` | 512×512 | Android adaptive |
| `apple-touch-icon.png` | 180×180 | iOS home screen |

UI icons (`coins.svg`, `book.svg`, …) are separate — used by `<KidIcon />`.
